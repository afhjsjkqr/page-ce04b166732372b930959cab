探索者

探索者是面向跨境协作、学术访问与流媒体观看的网络加速服务。本页集中说明官方套餐、机场订阅方式，以及 Windows、macOS、Android、iOS 与路由环境的客户端选择，帮助你完成一次清晰、可核对的接入。

探索者 VPN 与探索者机场共用同一套订阅体系：你先选定流量与设备额度，再把订阅导入常用客户端，按节点延迟与用途切换线路。页面不堆砌空洞口号，只保留可执行的套餐参数、客户端路径与操作顺序，便于对照官网下载入口完成配置。

品牌简介

探索者把「可预期的带宽」和「可管理的设备数」作为产品核心。基础版覆盖日常网页与轻量视频；旗舰版增加 IPLC 游戏优化与原生流媒体解锁；团队版面向多终端协作与定制路由。所有套餐均按月结算，年付可锁定全年单价。

作为探索者官方网站的信息页，这里同时承担加速器说明与客户端下载导览。订阅链接由账户中心签发，导入后由客户端负责测速、分流与故障切换，避免在浏览器里反复手工改代理。

为什么先选客户端

同一份机场订阅，在不同客户端里的分流规则、UDP 支持与系统托盘体验并不相同。探索者建议先确定主力设备，再决定 Clash Meta、sing-box、Shadowrocket 或 Surge 中的哪一条路径，减少重复导入。

  • 桌面端优先图形界面与系统代理开关
  • 移动端优先一键连接与规则订阅更新
  • 路由端优先稳定 DNS 与设备级分流

客户端选择与官方下载指引

选择原则

探索者客户端下载强调「订阅兼容」而不是绑定单一 App。只要客户端能解析标准订阅并支持常见协议，即可接入探索者机场。下列组合经过长期使用验证，适合作为默认方案。

桌面办公选 Clash Verge 或 Clash Meta 内核图形版，便于切换系统代理；移动观影选 Clash Meta for Android 或 iOS 上的 Shadowrocket / Stash；需要精细分流与脚本时再考虑 Surge。路由器用户可把订阅写入 OpenWrt 上的 sing-box 或 passwall，让家庭设备共享同一条加速通道。

官方下载入口与套餐开通位于账户中心。请只从探索者官网获取订阅，避免第三方镜像改写节点。完成付款后复制订阅地址，在客户端中选择「从 URL 更新」，首次连接建议使用延迟最低的普通节点做连通性测试，再切换 IPLC 或流媒体专用线路。

按系统对照

  • Windows：Clash Verge、v2rayN。导入订阅后开启系统代理，浏览器无需再装插件。
  • macOS：ClashX Meta、Surge。菜单栏切换节点，适合长时间挂起会议软件。
  • Android：Clash Meta、sing-box。建议允许 VPN 常驻并关闭省电限制。
  • iOS / iPadOS：Shadowrocket、Stash、Quantumult X。通过订阅 URL 拉取规则。
  • Linux / 路由器：Clash Meta 命令行或 sing-box，配合分流规则覆盖整网设备。

客户端本身是开源或第三方工具，探索者提供的是可导入的机场订阅与节点质量。更新客户端时保留原有配置文件，以免丢失自定义规则。

使用场景

跨境办公与会议

远程桌面、企业邮箱与会议软件对延迟抖动敏感。旗舰版 IPLC 线路适合固定时段的跨国会议；团队版可把办公网段单独走专线，其余流量走普通节点，避免抢占带宽。

流媒体与资料站

基础版可覆盖常规网页与部分视频站点；需要稳定解锁时选择旗舰版全节点原生流媒体。建议在客户端为视频域名单独分流，减少其它应用抢占会话。

游戏与多设备家庭

游戏加速优先 UDP 畅通的 IPLC 节点。多成员共用时选团队版 20 设备额度，在路由端统一订阅，手机与主机不必各自登录。流量以实际传输计，下载更新建议切回本地网络。

操作说明

  1. 确认套餐。按设备数量与月流量选择基础版、旗舰版或团队版，年付适合长期固定使用。
  2. 开通并复制订阅。在探索者官方网站账户中心生成订阅链接，不要把链接发到公开群组。
  3. 安装对应客户端。根据上一节对照表下载客户端，安装后允许创建 VPN 配置或系统代理。
  4. 导入并更新规则。选择「订阅 URL」，等待节点列表出现。必要时开启自动更新，周期可设为 24 小时。
  5. 连通性检查。先连普通线路访问网页，再测目标站点。游戏与 4K 播放再切专用节点。
  6. 日常维护。流量将尽时升级套餐；节点超时先更新订阅，再换线路，而不是反复重装客户端。

若多台设备共用一份订阅，请在客户端设置里限制同时在线数不超过套餐额度。超过额度时新设备会连接失败，已在线会话通常不受影响。

常见问题

探索者是什么，和普通加速器有何不同？

探索者是提供机场订阅的网络加速服务，也就是把可用节点、流量额度与设备数打包成套餐。与只能固定一个出口的单机加速器相比，探索者 VPN 允许在客户端里按延迟、流媒体或游戏用途切换线路，并由官方网站统一管理续费与订阅更新。

如何完成客户端下载并把订阅导入？

先在本页「客户端选择」确定系统对应的软件，从探索者官网下载入口进入账户中心复制订阅 URL。打开客户端的订阅或 Profiles 页面，粘贴 URL 并更新。导入成功后会出现节点分组。第一次请选延迟较低的普通节点，确认系统代理或 VPN 开关已打开，再访问需要加速的站点。

基础版、旗舰版和团队版该怎么选？

个人轻度浏览与三台设备以内选基础版（每月 100GB）。需要原生流媒体、游戏 IPLC 和优先工单选旗舰版（每月 300GB、五台设备）。工作室、家庭路由整网共享或需要定制路由选团队版（每月 1000GB、二十台设备与专属客户经理）。年付价格相当于缴纳十个月月费。

同时在线设备超限会怎样？流量用尽如何处理？

超过套餐允许的同时在线台数时，新接入会失败，需要先断开闲置设备。流量在每个自然月重置，用尽后加速通道会降速或暂停，可在官网升级到更高档位，升级后额度按新套餐立即生效。未用完的当月流量不结转到下月。

节点连不上或视频无法解锁时怎么排查？

按顺序处理：更新订阅、更换同分组其它节点、检查客户端是否开启 TUN/系统代理、确认没有多个 VPN 软件抢路由。流媒体请使用旗舰版或团队版标注可解锁的线路，并避免把下载工具跑在同一会话里。若持续失败，旗舰版与团队版可通过优先工单提交客户端日志时间戳。

探索者官方下载是否必须使用指定 App？

不强制唯一 App。探索者官方网站提供订阅，兼容 Clash 系、sing-box、Shadowrocket、Stash、Surge 等能识别标准订阅的客户端。指定列表只是为了降低配置失败率。请避免来路不明的改装客户端，以免订阅被截取。路由器方案适合希望手机不单独开 VPN 的家庭环境。

团队版定制路由包含哪些内容？

团队版可按域名、IP 段或公司内网出口划分规则，例如会议软件走 IPLC、大文件同步走高带宽 VIP 节点、国内站点直连。具体规则由专属客户经理与你确认后写入订阅侧或客户端配置模板，避免每台电脑手工维护。
